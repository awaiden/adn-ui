**adn-ui** is an open-source collection of accessible, styled, copy-and-paste UI components built for **React 19** (framework agnostic), styled using **Tailwind CSS v4** and OKLCH color design tokens.

## Key Features

<Cards>
  <Card title="Base UI Powered" icon="star">
    Built on top of `@base-ui/react`, offering accessible primitives with keyboard
    navigation and focus management.
  </Card>
  <Card title="Tailwind CSS v4 & OKLCH" icon="palette">
    Leverages Tailwind v4 CSS variables and OKLCH color spaces for dark mode and dynamic theme
    tokens.
  </Card>
  <Card title="Single-File Slots" icon="document">
    Clean multi-file architecture with compound object exports, type safety, and tailwind-variants
    (`tv()`).
  </Card>
  <Card title="Copy & Paste Registry" icon="laptop">
    Integrates with `registry.json` allowing quick component installation into your own codebase.
  </Card>
  <Card title="AI-Friendly JSDoc" icon="sparkles">
    Every component includes JSDoc `@see` annotations pointing directly to raw markdown docs
    (`/llms.mdx/docs/...`) for AI context.
  </Card>
</Cards>

## Tech Stack

- **Framework**: Framework Agnostic (React 19)
- **Primitives**: `@base-ui/react`
- **Styling**: Tailwind CSS v4
- **Variants**: `tailwind-variants` (`tv()`)

## Using the `@adn-ui` namespace (shadcn CLI)

You can install `adn-ui` components via the `shadcn` CLI using a namespace alias. First initialize `shadcn`, then configure the single canonical registry in `components.json` to point to `ui.awaiden.com`.

1. Initialize `shadcn` (run first):

```bash
npx shadcn@latest init
```

2. Default `components.json` (single canonical registry):

```json
{
  "registries": { "@adn-ui": "https://ui.awaiden.com/r/{name}.json" }
}
```

3. Install with the CLI (no global install required):

```bash
npx shadcn@latest add @adn-ui/button
```

4. View the manifest before installing:

```bash
npx shadcn@latest view @adn-ui/button
```

Keep manifests private if they include internal resources. Use `ui.awaiden.com` as the single canonical registry source.
