# Installing adn-ui Components

**adn-ui** is built as a custom [shadcn registry](https://ui.shadcn.com/docs/registry/getting-started). Instead of installing a heavy NPM package dependency, you copy components directly into your codebase using the official `shadcn` CLI.

---

## 🚀 Quick Start

You can install `adn-ui` components in three simple ways:

<Tabs items={['Method 1: Namespace (Recommended)', 'Method 2: Direct URL', 'Method 3: MCP Server (AI Assistants)']}>
  <Tab value="Method 1: Namespace (Recommended)">
    Configure the `@adn-ui` namespace once in your project, then install any component by name.

    <Steps>
      <Step>
        ### Initialize `shadcn` in your project
        If you haven't already initialized `shadcn` in your project, run:
        ```bash
        npx shadcn@latest init
        ```
      </Step>

      <Step>
        ### Add `@adn-ui` to `components.json`
        Open your project's `components.json` file and add the `@adn-ui` registry mapping under `registries`:
        ```json title="components.json"
        {
          "registries": {
            "@adn-ui": "https://ui.awaiden.com/r/{name}.json"
          }
        }
        ```
      </Step>

      <Step>
        ### Add components to your project
        Now you can add any `adn-ui` component using the namespace alias:
        ```bash
        npx shadcn@latest add @adn-ui/button
        ```
      </Step>
    </Steps>

  </Tab>

  <Tab value="Method 2: Direct URL">
    You can also install components directly without modifying `components.json` by providing the direct registry JSON URL.

    ```bash
    npx shadcn@latest add https://ui.awaiden.com/r/button.json
    ```

    Install multiple components at once:
    ```bash
    npx shadcn@latest add https://ui.awaiden.com/r/button.json https://ui.awaiden.com/r/card.json https://ui.awaiden.com/r/dialog.json
    ```

  </Tab>

  <Tab value="Method 3: MCP Server (AI Assistants)">
    Connect your AI assistant (Cursor, Antigravity, Claude Code, Windsurf, etc.) directly to the `adn-ui` MCP server to let AI automatically inspect, search, and add components to your workspace.

    Set your MCP SSE Endpoint:
    ```
    https://ui.awaiden.com/api/mcp/sse
    ```

    For detailed client configurations and available MCP tools, see the [MCP Server Integration Guide](/docs/getting-started/mcp).
  </Tab>
</Tabs>

## 🛠️ How the Registry Works

The `shadcn` registry architecture operates as a decentralized distribution system (see [shadcn registry docs](https://ui.shadcn.com/docs/registry/getting-started)):

1. **Manifest Fetching**: When you run `npx shadcn@latest add @adn-ui/button`, the CLI fetches the JSON item manifest from `https://ui.awaiden.com/r/button.json`.
2. **Dependency Resolution**: The CLI inspects the manifest's `dependencies` (such as `@base-ui/react`, `tailwind-variants`, `tailwind-merge`) and installs them into your `package.json`.
3. **File Placement**: The CLI places component files (`.tsx`, `.variants.ts`, `.css`, `.context.ts`) directly into your project's `src/components/ui/button/` directory.
4. **Full Ownership**: You own the code! Modify, theme, or extend component variants directly in your repository.

## ⚙️ Project Setup for Tailwind CSS v4 Component CSS Files

`adn-ui` uses modular `.css` files per component (e.g., `card.css`, `button.css`) which utilize `@apply` directives. In **Tailwind CSS v4**, standalone CSS files with `@apply` rules require an explicit `@reference` to your main CSS file.

<Callout type="warn" title="Preventing @apply / unknown directive Errors">
  Without auto-reference plugins, PostCSS will throw runtime or build errors such as: **`Unknown
  directive @apply ... (did you forget @reference?)`** Configure auto-referencing in your build
  setup so PostCSS resolves utility classes automatically:
</Callout>

<Tabs items={['Next.js', 'Vite', 'MCP Tool (AI Setup)']}>
  <Tab value="Next.js">
    Configure `postcss-tw-auto-reference` in your `postcss.config.mjs`:

    ```js title="postcss.config.mjs"
    const config = {
      plugins: {
        "postcss-tw-auto-reference": {
          globalCssPath: "app/globals.css", // or "src/app/global.css"
        },
        "@tailwindcss/postcss": {},
      },
    };

    export default config;
    ```

  </Tab>

  <Tab value="Vite">
    Configure `vite-plugin-tw-auto-reference` in your `vite.config.ts`:

    ```ts title="vite.config.ts"
    import { defineConfig } from "vite";
    import tailwindAutoReference from "vite-plugin-tw-auto-reference";

    export default defineConfig({
      plugins: [
        tailwindAutoReference({
          globalCssPath: "src/index.css",
        }),
      ],
    });
    ```

  </Tab>

  <Tab value="MCP Tool (AI Setup)">
    Configure the **adn-ui MCP Tool** in your AI editor (Cursor, Antigravity, Claude Code, Windsurf) to allow your AI assistant to automatically discover, inspect, and install Tailwind CSS v4 components.

    Add the MCP SSE Endpoint to your editor's MCP server configuration:

    ```json title="mcp-config.json"
    {
      "mcpServers": {
        "adn-ui": {
          "url": "https://ui.awaiden.com/api/mcp/sse",
          "transport": "sse"
        }
      }
    }
    ```

    Exposed MCP tools for AI assistants:
    - `init_adn_ui`: Get complete project integration guide, `components.json` config, and PostCSS/Vite setup.
    - `list_components`: List all available components and file structures (`.tsx`, `.variants.ts`, `.css`).
    - `get_component`: Retrieve component source code, Tailwind v4 CSS, and variant definitions.
    - `search_components`: Search components by name or keyword.
    - `get_component_doc`: Retrieve component documentation and usage examples.
    - `get_registry_item`: Fetch the raw shadcn JSON registry manifest.
    - `add_component`: Get installation commands (`npx shadcn@latest add`), registry URL, and manifest details.
  </Tab>

  <Tab value="Agent Skills (npx skills)">
    Equip your AI agent (Antigravity, Cursor, Claude Code, Windsurf) with the complete **adn-ui** design system rules, Base UI primitive state bindings, and component standards:

    ```bash
    npx skills add awaiden/adn-ui
    ```

    This command installs `.agents/skills/adn-ui` into your project workspace so AI assistants automatically understand `adn-ui` modular slot patterns, icon rules, and validation workflows.
  </Tab>
</Tabs>

## Useful CLI Commands

Here are essential commands for managing your components:

| Command                                             | Description                                                                  |
| :-------------------------------------------------- | :--------------------------------------------------------------------------- |
| `npx shadcn@latest add @adn-ui/button`              | Installs the specified component and its required npm dependencies.          |
| `npx shadcn@latest add @adn-ui/card @adn-ui/dialog` | Installs multiple components in a single command.                            |
| `npx shadcn@latest view @adn-ui/button`             | Inspects a component's JSON manifest and file list before adding.            |
| `npx shadcn@latest add --overwrite @adn-ui/button`  | Overwrites existing component files in your project with the latest version. |

## Example Usage in Code

Once installed, import and use the component compound objects or named exports in your application:

```tsx title="src/app/page.tsx"
import { Button } from "@/components/ui/button";
import { CardRoot, CardHeader, CardTitle, CardContent } from "@/components/ui/card";

export default function ExamplePage() {
  return (
    <CardRoot className="max-w-md mx-auto my-8">
      <CardHeader>
        <CardTitle>Welcome to adn-ui</CardTitle>
      </CardHeader>
      <CardContent className="space-y-4">
        <p className="text-muted-foreground">
          Accessible Base UI primitives styled with Tailwind CSS v4 OKLCH tokens.
        </p>
        <Button variant="primary" size="md">
          Get Started
        </Button>
      </CardContent>
    </CardRoot>
  );
}
```

## 🤖 AI-Friendly JSDoc & MCP Server Integration

All `adn-ui` components include JSDoc `@see` annotations linking directly to raw markdown documentation URLs (powered by the `/llms.mdx/docs/...` route):

```tsx
/**
 * @see https://ui.awaiden.com/llms.mdx/docs/components/button/content.md
 */
export const Button = ...
```

When using AI coding assistants (such as Antigravity, Cursor, Claude Code, or GitHub Copilot), the AI model reads the JSDoc `@see` link on hover or definition inspection to fetch component specifications.

### 🔌 Model Context Protocol (MCP) Server

`adn-ui` includes a built-in **Model Context Protocol (MCP)** server endpoint that allows AI tools to query, search, inspect code, and install components automatically.

- **SSE Endpoint**: `https://ui.awaiden.com/api/mcp/sse`

For detailed setup instructions for Cursor, Claude Code, and Antigravity, refer to the [MCP Server Integration Guide](/docs/getting-started/mcp).

## ❓ Frequently Asked Questions

<Callout type="info" title="Do I need to install an adn-ui npm package?">
  No package installation is required! `adn-ui` components are copy-and-paste primitives installed
  straight into your codebase so you have 100% control over design and implementation.
</Callout>

<Callout type="info" title="How do I connect AI tools to adn-ui via MCP?">
  Add `https://ui.awaiden.com/api/mcp/sse` to your editor's MCP server settings (Cursor, Claude Desktop, Antigravity). Check out the [MCP Integration Guide](/docs/getting-started/mcp) for client configs.
</Callout>

<Callout type="warn" title="What if I get 'Unknown registry @adn-ui'?">
  Ensure `"registries": { "@adn-ui": "https://ui.awaiden.com/r/{name}.json" }` is included in your `components.json` file.
</Callout>

<Callout
  type="warn"
  title="What if I get 'Unknown directive @apply' or 'did you forget @reference?'"
>
  This happens because Tailwind v4 needs to know where global theme definitions are located when
  compiling standalone component `.css` files. See the [PostCSS / Vite
  setup](#-project-setup-for-tailwind-css-v4-component-css-files) section above to configure
  `postcss-tw-auto-reference` or `vite-plugin-tw-auto-reference`.
</Callout>
