The `Pagination` component provides accessible page navigation controls with page links, next/previous actions, and ellipsis indicators.

## Usage

```tsx
import { Pagination } from "@/components/ui/pagination";

export function ExamplePagination() {
  return (
    <Pagination.Root>
      <Pagination.Content>
        <Pagination.Item>
          <Pagination.Previous href="#" />
        </Pagination.Item>
        <Pagination.Item>
          <Pagination.Link href="#">1</Pagination.Link>
        </Pagination.Item>
        <Pagination.Item>
          <Pagination.Link href="#" isActive>
            2
          </Pagination.Link>
        </Pagination.Item>
        <Pagination.Item>
          <Pagination.Link href="#">3</Pagination.Link>
        </Pagination.Item>
        <Pagination.Item>
          <Pagination.Ellipsis />
        </Pagination.Item>
        <Pagination.Item>
          <Pagination.Next href="#" />
        </Pagination.Item>
      </Pagination.Content>
    </Pagination.Root>
  );
}
```

## API Reference

### Pagination.Root Props

| Prop   | Type                   | Default | Description                   |
| :----- | :--------------------- | :------ | :---------------------------- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'`  | Visual size of the component. |

### Pagination.Link Props

| Prop       | Type      | Default | Description                                              |
| :--------- | :-------- | :------ | :------------------------------------------------------- |
| `isActive` | `boolean` | `false` | Sets active styling and `aria-current="page"` attribute. |
