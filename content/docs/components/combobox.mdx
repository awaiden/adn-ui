The `Combobox` component combines a text input with a filterable dropdown popup for selecting from predefined option lists.

## Usage

```tsx
import { Combobox } from "@/components/ui/combobox";

const fruits = [
  { label: "Apple", value: "apple" },
  { label: "Banana", value: "banana" },
  { label: "Orange", value: "orange" },
];

export function ExampleCombobox() {
  return (
    <Combobox.Root items={fruits}>
      <Combobox.InputGroup>
        <Combobox.Input placeholder="Select fruit..." />
        <Combobox.Clear />
        <Combobox.Trigger />
      </Combobox.InputGroup>
      <Combobox.Portal>
        <Combobox.Positioner sideOffset={4}>
          <Combobox.Popup>
            <Combobox.Empty>No items found.</Combobox.Empty>
            <Combobox.List>
              {(fruit) => (
                <Combobox.Item key={fruit.value} value={fruit}>
                  <Combobox.ItemIndicator />
                  <span>{fruit.label}</span>
                </Combobox.Item>
              )}
            </Combobox.List>
          </Combobox.Popup>
        </Combobox.Positioner>
      </Combobox.Portal>
    </Combobox.Root>
  );
}
```

## API Reference

### Combobox.Root Props

| Prop            | Type                   | Default     | Description                                       |
| :-------------- | :--------------------- | :---------- | :------------------------------------------------ |
| `items`         | `Array`                | `[]`        | Predefined list of items available for selection. |
| `size`          | `'sm' \| 'md' \| 'lg'` | `'md'`      | Component size.                                   |
| `multiple`      | `boolean`              | `false`     | Enables multi-item selection with chips.          |
| `value`         | `any`                  | `undefined` | Controlled value.                                 |
| `onValueChange` | `(value: any) => void` | `undefined` | Event handler called when selection changes.      |
