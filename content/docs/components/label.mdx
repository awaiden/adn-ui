The `Label` component renders an accessible label for form controls with support for sizes and disabled state styling.

## Usage

```tsx
import { Label } from "@/components/ui/label";
import { Input } from "@/components/ui/input";

export function ExampleLabel() {
  return (
    <div className="flex flex-col gap-2">
      <Label htmlFor="email">Email address</Label>
      <Input id="email" type="email" placeholder="you@example.com" />
    </div>
  );
}
```

## API Reference

### Label Props

| Prop      | Type                   | Default | Description              |
| :-------- | :--------------------- | :------ | :----------------------- |
| `htmlFor` | `string`               | `undefined` | ID of the form control. |
| `size`    | `'sm' \| 'md' \| 'lg'` | `'md'`  | Size variant for label.  |
