The `AspectRatio` component constrains content to a specific width-to-height aspect ratio.

## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio";

export function ExampleAspectRatio() {
  return (
    <div className="w-[400px]">
      <AspectRatio ratio={16 / 9} className="bg-muted flex items-center justify-center rounded-lg border">
        <span>16 / 9 Content</span>
      </AspectRatio>
    </div>
  );
}
```

### AspectRatio Props

| Prop    | Type     | Default  | Description                             |
