The `Spinner` component renders an accessible SVG loading spinner for indicating asynchronous actions or loading states.

## Usage

```tsx
import { Spinner } from "@/components/ui/spinner";

export function ExampleSpinner() {
  return <Spinner size="md" />;
}
```

## API Reference

### Spinner Props

| Prop      | Type                              | Default     | Description                            |
| :-------- | :-------------------------------- | :---------- | :------------------------------------- |
| `size`    | `'sm' \| 'md' \| 'lg' \| 'xl'`   | `'md'`      | Dimension size of the spinner.         |
| `variant` | `'default' \| 'muted' \| 'primary'` | `'default'` | Visual color variant of the spinner.  |
