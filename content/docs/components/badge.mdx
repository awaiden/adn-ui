The `Badge` component renders small visual indicators for statuses, categories, or notifications.

## Usage

```tsx
import { Badge } from "@/components/ui/badge";

export function ExampleBadge() {
  return <Badge.Root variant="secondary">New</Badge.Root>;
}
```

## API Reference

### Badge.Root Props

| Prop      | Type                                                     | Default     | Description                      |
| :-------- | :------------------------------------------------------- | :---------- | :------------------------------- |
| `variant` | `'default' \| 'secondary' \| 'destructive' \| 'outline'` | `'default'` | Visual color style of the badge. |
| `size`    | `'sm' \| 'md' \| 'lg'`                                   | `'md'`      | Size variant of the badge.       |
