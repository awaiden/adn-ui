The `NativeSelect` component wraps the HTML `<select>` element with consistent styling and a custom dropdown indicator.

## Usage

```tsx
import { NativeSelect } from "@/components/ui/native-select";

export function ExampleNativeSelect() {
  return (
    <NativeSelect defaultValue="usd">
      <NativeSelect.Option value="usd">USD ($)</NativeSelect.Option>
      <NativeSelect.Option value="eur">EUR (€)</NativeSelect.Option>
      <NativeSelect.Option value="gbp">GBP (£)</NativeSelect.Option>
    </NativeSelect>
  );
}
```

## API Reference

### NativeSelect Props

| Prop      | Type                   | Default     | Description                              |
| :-------- | :--------------------- | :---------- | :--------------------------------------- |
| `size`    | `'sm' \| 'md' \| 'lg'` | `'md'`      | Size variant for select.                 |
| `variant` | `'default' \| 'outline'`| `'default'` | Visual style variant.                    |
| `icon`    | `React.ReactNode`      | `undefined` | Custom icon element for dropdown arrow.  |
