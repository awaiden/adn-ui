The `Separator` component visually or semantically separates content in horizontal or vertical layouts with built-in accessibility.

## Usage

```tsx
import { Separator } from "@/components/ui/separator";

export function ExampleSeparator() {
  return (
    <div className="flex h-5 items-center gap-4 text-sm font-medium">
      <span>Blog</span>
      <Separator.Root orientation="vertical" />
      <span>Pricing</span>
      <Separator.Root orientation="vertical" />
      <span>Docs</span>
    </div>
  );
}
```

## API Reference

### Separator.Root Props

| Prop          | Type                         | Default        | Description                                            |
| :------------ | :--------------------------- | :------------- | :----------------------------------------------------- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Orientation layout direction of the separator element. |
