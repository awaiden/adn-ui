The `Switch` component toggles the state of a single setting between enabled (on) and disabled (off).

## Usage

```tsx
import { Switch } from "@/components/ui/switch";

export function ExampleSwitch() {
  return (
    <label className="flex items-center gap-3 text-sm font-medium">
      <Switch.Root defaultChecked>
        <Switch.Thumb />
      </Switch.Root>
      Enable Airplane Mode
    </label>
  );
}
```

## API Reference

### Switch.Root Props

| Prop              | Type                         | Default     | Description                                     |
| :---------------- | :--------------------------- | :---------- | :---------------------------------------------- |
| `checked`         | `boolean`                    | `undefined` | Controlled toggle state of the switch.          |
| `defaultChecked`  | `boolean`                    | `false`     | Initial uncontrolled toggle state.              |
| `onCheckedChange` | `(checked: boolean) => void` | `undefined` | Event handler called when toggle state changes. |
| `disabled`        | `boolean`                    | `false`     | Disables user interaction.                      |
| `size`            | `'sm' \| 'md' \| 'lg'`       | `'md'`      | Physical size variant of the switch control.    |
