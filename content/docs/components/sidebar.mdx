The `Sidebar` component provides an accessible, collapsible layout structure for application navigation.

## Usage

```tsx
import { Sidebar } from "@/components/ui/sidebar";

export function ExampleSidebar() {
  return (
    <Sidebar.Provider>
      <Sidebar.Root>
        <Sidebar.Header>
          <span>App Header</span>
          <Sidebar.Trigger />
        </Sidebar.Header>
        <Sidebar.Content>
          <Sidebar.Group>
            <Sidebar.GroupLabel>Navigation</Sidebar.GroupLabel>
            <Sidebar.GroupContent>
              <Sidebar.Menu>
                <Sidebar.MenuItem>
                  <Sidebar.MenuButton isActive>Dashboard</Sidebar.MenuButton>
                </Sidebar.MenuItem>
                <Sidebar.MenuItem>
                  <Sidebar.MenuButton>Settings</Sidebar.MenuButton>
                </Sidebar.MenuItem>
              </Sidebar.Menu>
            </Sidebar.GroupContent>
          </Sidebar.Group>
        </Sidebar.Content>
      </Sidebar.Root>
    </Sidebar.Provider>
  );
}
```

## API Reference

### Sidebar.Provider Props

| Prop          | Type                   | Default | Description                            |
| :------------ | :--------------------- | :------ | :------------------------------------- |
| `defaultOpen` | `boolean`              | `true`  | Initial uncontrolled open state.       |
| `open`        | `boolean`              | -       | Controlled open state.                 |
| `onOpenChange`| `(open: boolean) => void` | -     | Callback fired when open state changes.|
