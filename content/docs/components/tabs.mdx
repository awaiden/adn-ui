The `Tabs` component manages views organized into tabbed panels with smooth indicator animations and variant styling.

## Usage

```tsx
import { Tabs } from "@/components/ui/tabs";

export function ExampleTabs() {
  return (
    <Tabs.Root defaultValue="overview" variant="pills">
      <Tabs.List>
        <Tabs.Tab value="overview">Overview</Tabs.Tab>
        <Tabs.Tab value="settings">Settings</Tabs.Tab>
        <Tabs.Indicator />
      </Tabs.List>
      <Tabs.Panel value="overview">Overview content goes here.</Tabs.Panel>
      <Tabs.Panel value="settings">Settings content goes here.</Tabs.Panel>
    </Tabs.Root>
  );
}
```

## Anatomy

```tsx
import { Tabs } from "@base-ui/react/tabs";

<Tabs.Root>
  <Tabs.List>
    <Tabs.Tab />
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Panel />
</Tabs.Root>;
```

## API Reference

### Tabs.Root Props

| Prop           | Type                                  | Default     | Description                                         |
| :------------- | :------------------------------------ | :---------- | :-------------------------------------------------- |
| `value`        | `string`                              | `undefined` | Controlled value of the active tab.                 |
| `defaultValue` | `string`                              | `undefined` | Initial uncontrolled active tab.                    |
| `variant`      | `'default' \| 'pills' \| 'underline'` | `'default'` | Visual style of the tab list and active indicators. |
| `size`         | `'sm' \| 'md' \| 'lg'`                | `'md'`      | Size scale for tabs and padding.                    |
