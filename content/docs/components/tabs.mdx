The `Tabs` component manages views organized into tabbed panels with smooth indicator animations and variant styling.

## Usage

```tsx
import { Tabs } from "@/components/ui/tabs";

export function ExampleTabs() {
  return (
    <Tabs.Root defaultValue="overview" variant="pills">
      <Tabs.List>
        <Tabs.Tab value="overview">Overview</Tabs.Tab>
        <Tabs.Tab value="settings">Settings</Tabs.Tab>
        <Tabs.Indicator />
      </Tabs.List>
      <Tabs.Panel value="overview">Overview content goes here.</Tabs.Panel>
      <Tabs.Panel value="settings">Settings content goes here.</Tabs.Panel>
    </Tabs.Root>
  );
}
```

## Custom Styling

Apply custom active tab indicators, background pills, or text colors via `className`:

```tsx
<Tabs.List className="bg-slate-900 border border-slate-800 p-1 rounded-xl">
  <Tabs.Tab value="active" className="data-[selected]:bg-indigo-600 data-[selected]:text-white font-medium">
    Active Tab
  </Tabs.Tab>
</Tabs.List>
```

## Styling & Class Names

Target internal tabs CSS slots for custom overrides:

| Class Name | Element / Slot | Description |
| :--- | :--- | :--- |
| `.tabs` | Root container | Tabs root wrapper container. |
| `.tabs__list` | Tab list row | Horizontal or vertical tab list row. |
| `.tabs__tab` | Tab button | Individual tab trigger element (`data-[selected]`). |
| `.tabs__indicator` | Sliding indicator | Animated active tab indicator bar or pill background. |
| `.tabs__panel` | Content panel | Content panel container corresponding to active tab. |

## Anatomy

```tsx
import { Tabs } from "@base-ui/react/tabs";

<Tabs.Root>
  <Tabs.List>
    <Tabs.Tab />
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Panel />
</Tabs.Root>;
```

## API Reference

### Tabs.Root Props

| Prop           | Type                                  | Default     | Description                                         |
| :------------- | :------------------------------------ | :---------- | :-------------------------------------------------- |
| `value`        | `string`                              | `undefined` | Controlled value of the active tab.                 |
| `defaultValue` | `string`                              | `undefined` | Initial uncontrolled active tab.                    |
| `variant`      | `'default' \| 'pills' \| 'underline'` | `'default'` | Visual style of the tab list and active indicators. |
| `size`         | `'sm' \| 'md' \| 'lg'`                | `'md'`      | Size scale for tabs and padding.                    |
