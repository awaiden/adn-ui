The `Field` component wraps form controls to handle labels, description messages, and automatic HTML5 validation error matching.

## Usage

```tsx
import { Field } from "@/components/ui/field";

export function ExampleField() {
  return (
    <Field.Root>
      <Field.Label>Name</Field.Label>
      <Field.Control required placeholder="Required" />
      <Field.Error match="valueMissing">Please enter your name.</Field.Error>
      <Field.Description>Visible on your profile.</Field.Description>
    </Field.Root>
  );
}
```


## API Reference

### Field.Root Props

| Prop             | Type                                   | Default      | Description                               |
| :--------------- | :------------------------------------- | :----------- | :---------------------------------------- |
| `name`           | `string`                               | `undefined`  | Identifies the field in form submissions. |
| `disabled`       | `boolean`                              | `false`      | Disables user interaction.                |
| `invalid`        | `boolean`                              | `undefined`  | Forces invalid state.                     |
| `validationMode` | `'onSubmit' \| 'onBlur' \| 'onChange'` | `'onSubmit'` | Determines when field validation is run.  |

### Field.Error Props

| Prop    | Type                          | Default     | Description                                                |
| :------ | :---------------------------- | :---------- | :--------------------------------------------------------- |
| `match` | `ValidityStateKey \| boolean` | `undefined` | Validity state key matching rule to display error message. |
